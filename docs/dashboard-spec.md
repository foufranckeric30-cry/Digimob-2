# Spécification du tableau de bord

Le tableau de bord présente le nom, le numéro client, l'abonnement actuel, son expiration et son
statut, ainsi que les offres, actions rapides, dernières opérations et notifications importantes.

Il expose les états chargement, données disponibles, aucune donnée, erreur réseau et utilisateur non
connecté. Les actions rapides naviguent vers abonnement, offres/renouvellement, paiements, historique,
notifications, profil et support. Toute route privée exige une session active.
